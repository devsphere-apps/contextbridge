# ContextBridge

> Export your Claude projects into portable Markdown knowledge bases and continue them in ChatGPT and other AI platforms.

ContextBridge converts AI assistant exports into structured Markdown knowledge bases that preserve conversations, context, and project history so you can continue your work anywhere.

## Vision

Move project knowledge instead of starting over.

Instead of locking conversations inside a single AI platform, ContextBridge transforms them into portable knowledge that can be indexed, searched, and reused across different AI assistants.

---

# Features

- ✅ Claude export loader
- ✅ Claude conversation parser
- ✅ Claude message parser
- ✅ Project inspection
- ✅ Universal `ProjectContext`
- ✅ Markdown knowledge base export
- ✅ Export every conversation
- ✅ Export a single conversation by UUID
- ✅ Export directly from a Claude conversation URL

# Export Your Project from Claude

Before using ContextBridge, you need to export your data from Claude.

## Step 1 — Open Claude

Go to:

```
https://claude.ai
```

Log in to your account.

---

## Step 2 — Open Settings

Click your profile icon in the bottom-left corner.

Open:

```
Settings
```

---

## Step 3 — Export Your Data

Navigate to:

```
Settings → Data & Privacy → Export Data
```

Request your export.

Claude will prepare your data and send you a download link by email.

---

## Step 4 — Download the Export

Download the exported ZIP file from the email.

Example:

```
claude-export.zip
```

---

## Step 5 — Extract the ZIP

Extract it to a folder.

Example:

```
~/Downloads/claude-export/
```

The extracted folder should contain files similar to:

```text
claude-export/
├── conversations.json
├── memories.json
├── projects/
├── account.json
└── ...
```

This folder is the input for ContextBridge.

# Usage

## Show version

```bash
contextbridge version
```

---

## Inspect a Claude export

```bash
contextbridge inspect ~/Downloads/claude-export
```

Example output:

```text
✓ Claude export detected

Conversations: 230
Messages:      8275
```

---

## Export every conversation

```bash
contextbridge export \
~/Downloads/claude-export \
--format markdown \
--output exports
```

---

## Export a single conversation

Every Claude conversation has a unique UUID.

```bash
contextbridge export \
~/Downloads/claude-export \
--conversation c389aee2-0811-4326-a898-f3871969eaf7
```

---

## Export directly from a Claude conversation URL

Simply copy the conversation URL from your browser.

Example:

```text
https://claude.ai/chat/c389aee2-0811-4326-a898-f3871969eaf7
```

Then run:

```bash
contextbridge export \
~/Downloads/claude-export \
--url "https://claude.ai/chat/c389aee2-0811-4326-a898-f3871969eaf7"
```

# Continue Your Project in ChatGPT

After exporting your conversations, you can continue the same project inside ChatGPT.

## Step 1 — Create a ChatGPT Project

Create a new ChatGPT Project.

Example project name:

```
Customer Support Automation
```

or

```
AI Research Workspace
```

---

## Step 2 — Upload the exported Markdown

Upload one or more Markdown files generated by ContextBridge.

Example:

```text
exports/
├── Customer Support Automation.md
├── Product Requirements.md
├── Sprint Planning.md
└── AI Research Notes.md
```

Wait for ChatGPT to finish indexing the uploaded files.

---

## Step 3 — Verify the imported knowledge

Ask ChatGPT a few questions to verify the knowledge base.

Example prompts:

```
Summarize this project.
```

```
What is the overall architecture?
```

```
What modules are planned?
```

```
What are the open questions?
```

```
What are the next development tasks?
```

---

## Step 4 — Continue developing

Once ChatGPT has indexed the Markdown files, simply continue working.

Example prompts:

```
Read everything in the uploaded knowledge.

Tell me:

- what has already been decided
- what is still undecided
- what should be implemented next
```

```
Find every place where authentication was discussed.
```

```
Show me every decision related to the database schema.
```

```
What workflow was finally agreed upon?
```

```
What changed over time during the project?
```

```
Create an implementation plan for the remaining work.
```

```
Generate a technical specification from everything in the uploaded knowledge.
```

At this point, ChatGPT can use the exported knowledge as the foundation for continuing the project without manually copying conversations.
